# 🎌 Anime-data-Analysis Dashboard

An interactive **Anime Analysis Dashboard** designed to explore and analyze anime data using different categories such as type, genre, ratings, members, episodes, and popularity.

The dashboard provides an easy-to-understand visual representation of anime statistics and allows users to filter the data interactively.

## 📊 Dashboard Preview

![Anime Analysis Dashboard]

## 🎯 Project Objective

The main objective of this project is to analyze anime-related data and extract useful insights through an interactive dashboard.

The dashboard helps users understand:

- ⭐ Anime ratings
- 👥 Number of members
- 🎬 Number of episodes
- 📺 Anime types
- 🎭 Genres
- 🏆 Top-rated anime
- 📈 Rating distribution
- 🔎 Anime with the highest ratings


## 📌 Key Features

### 🔹 Interactive Filters

The dashboard contains multiple filters that allow users to explore the data based on:

- **Type**
- **Name**
- **Genre**
- **Top Anime**
- **Rating**

These filters dynamically update the dashboard visualizations.

### 🔹 KPI Cards

The dashboard displays important overall statistics:

| KPI | Description |
|---|---|
| ⭐ Sum of Rating | Total rating value |
| 🎬 Count of Anime | Total number of anime records |
| 📺 Sum of Episodes | Total episodes across anime |
| 👥 Sum of Members | Total members across anime |

### 🔹 Visualizations

The dashboard contains several visualizations:

**1. Sum of Average Rating by Type**

Shows the total average rating across different anime types such as:

- TV
- OVA
- Movie
- Special
- ONA
- Music

**2. Total Members by Type**

Displays the number of members associated with each anime type.

**3. Rating by Anime Name**

A detailed visual showing anime names along with their ratings.

**4. Rating by Name Treemap**

A treemap visualization showing anime based on their ratings.


## 📈 Key Metrics

Some of the major metrics displayed in the dashboard include:

- **78.10K** – Sum of Rating
- **12.29K** – Count of Anime
- **148,021** – Sum of Episodes
- **222M** – Sum of Members

> These values may change depending on the filters selected in the dashboard.


## 🗂️ Dataset

The dashboard is created using an anime dataset containing information such as:

- Anime ID
- Anime Name
- Genre
- Type
- Episodes
- Rating
- Members

The dataset can be used to analyze popularity, ratings, anime types, and audience engagement.


## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures
- **CSV Dataset** – Data source
